# Controle de Niveis de Agua - Agenda 11 DSI (Recuperacao)

Atividade de recuperacao da Agenda 11 de Desenvolvimento de Sistemas I.

## Descricao

Sistema em Python para monitoramento dos niveis de agua de um reservatorio, utilizando a biblioteca `colorama` para indicar a situacao com cores especificas:

- Nivel 1: Muito baixo (critico) - Vermelho
- Nivel 2: Baixo - Amarelo
- Nivel 3: Medio - Verde
- Nivel 4: Alto - Ciano
- Nivel 5: Muito alto (alerta) - Azul

## Como executar

1. Instalar as dependencias:
```bash
pip install -r requirements.txt
```

2. Executar o programa:
```bash
python main.py
```

3. Executar os testes unitarios:
```bash
python test_monitoramento.py
```
